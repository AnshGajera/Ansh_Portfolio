## 🔐 Authentication APIs

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| POST | `/api/auth/login` | No | Admin login with email/password |
| POST | `/api/auth/logout` | Yes | Admin logout (clears cookie) |
| GET | `/api/auth/me` | Yes | Get current admin info |
| POST | `/api/auth/register` | Yes | Register new admin (protected) |
| PUT | `/api/auth/update` | Yes | Update admin credentials |

## 📋 Data Models

### Project
```json
{
  "title": "string (required)",
  "slug": "string (required, unique)",
  "description": "string (required)",
  "projectMarkdown": "string (optional, rich content)",
  "tags": ["string"],
  "liveUrl": "string (optional)",
  "githubUrl": "string (optional)",
  "images": [{
    "url": "string",
    "caption": "string (optional)",
    "showOnProject": "boolean"
  }],
  "active": "boolean (default: true)",
  "featured": "boolean (default: false)",
  "priority": "number (lower = first)"
}
```

### Blog
```json
{
  "title": "string (required)",
  "slug": "string (required, unique)",
  "description": "string (required)",
  "tags": ["string"],
  "link": "string (optional, external link)",
  "image": "string (optional, cover image)",
  "active": "boolean",
  "featured": "boolean"
}
```

### Certification
```json
{
  "title": "string (required)",
  "slug": "string (required, unique)",
  "description": "string (required)",
  "tags": ["string"],
  "link": "string (optional)",
  "image": "string (optional)",
  "issuer": "string (required)",
  "issueDate": "date (required)",
  "expiryDate": "date (optional)",
  "credentialId": "string (optional)",
  "pdf": "string (optional, PDF URL)",
  "active": "boolean",
  "featured": "boolean"
}
```

## 🚀 Vercel Deployment Steps

### 1. Push to GitHub
```bash
cd backend
git add .
git commit -m "Ready for Vercel deployment"
git push origin main
```

### 2. Import to Vercel
1. Go to vercel.com → New Project
2. Import your GitHub repository
3. Select the `backend` folder as root directory

### 3. Add Environment Variables in Vercel Dashboard
| Variable | Value |
|----------|-------|
| `MONGODB_URI` | mongodb+srv://... |
| `JWT_SECRET` | your_secret_key |
| `CLOUDINARY_CLOUD_NAME` | dedm8zbh4 |
| `CLOUDINARY_API_KEY` | 745854171693991 |
| `CLOUDINARY_API_SECRET` | RIIeo88lbB1QA0dxvSw9rNsy10k |

### 4. Deploy!
Click "Deploy" and wait for build to complete.
